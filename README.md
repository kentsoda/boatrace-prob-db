# ボートレース条件別 確率データベース

ボートレースの過去データをもとに、「条件ごとの発生確率」を提示するデータベースです。
確率を表示することだけを目的としており、**期待値プラス・必勝・稼げるといった主張は一切しません。**

- **公開ページ（GitHub Pages）**
  - [確率DB](index.html) — 条件別に3連単 全120組番の発生率・95%信頼区間・平均払戻を表示
  - [日次分類](daily.html) — 翌日（前日夜に生成）の各レースを A〜E に分類した一覧
  - [答え合わせ](review.html) — 分類の予測と実際の結果を突き合わせた自己評価の記録

## このDBで分かること

- 条件（レース場、1号艇の勝率帯、出場選手の級別構成、モーター2連対率など）を選ぶと、その条件に該当した過去のレースで各組番がどのくらいの頻度で発生したか（発生率）が分かります。
- 確率はすべて過去データの発生頻度です。母数が小さい条件では信頼区間（95%CI）が大きく開きます。CIと的中数（母数）を必ず併せて見てください。

### データの範囲

- 確率DB v2: 2021年11月〜2026年10月の **276,913レース**。186セグメント（条件）×120組番。
- グレード・レース名カテゴリなど一部のセグメントは、データ源の制約で2026年5〜10月の値のまま据え置き（ページ内に期間注記あり）。

## A〜E分類とは

各レースが「堅く決着するか／荒れるか」を、前日までに分かる情報（出走表）だけから予測する分類です。

- 決着の堅さは、そのレースの**3連単払戻金額**で定義します。
  - A: 〜1,000円（堅い）／ B: 〜1,800円 ／ C: 〜3,440円 ／ D: 〜8,000円 ／ E: 8,000円超（荒れる）
  - 境界は学習期間（2026年1〜6月）の払戻分布の5分位で固定しています。
- 表示は断定ラベルではなく、A〜Eそれぞれの**確率分布**（例: A 40% / B 25% / …）です。
- 「堅い」と予測したレースでも実際に堅く決着するのは一部ですし、「荒れる」要因の多くは前日情報では捉えきれません。分類は確率分布として読んでください（実績の答え合わせは review ページで継続公開しています）。

## データ源

- BOAT RACE 公式サイト（boatrace.jp）の公開データ（出走表・競走成績）
- 公式アーカイブ（mbrace）の成績・番組データ
- BoatraceCSV（公式データのミラーCSV）

いずれも一般に公開されているデータで、再配布ではなく集計・分析結果の提示です。

## 注意事項（必ずお読みください）

- 掲載しているのは**過去の発生頻度（確率）だけ**です。当日の実際のオッズと照合して「買える／買えない」を判断するのは、**利用者自身**です。本サイトは期待値の判定や購入の推奨はしません。
- 確率は未来の結果を保証しません。**的中や利益は一切保証されません。**
- 「ウォッチリスト」は、過去データで一定の基準を満たした条件×組番を固定した追跡対象リストです。過去の実績であり、将来も同じ傾向が続く保証はありません。
- 舟券の購入は自己責任でお願いします。

## 更新について

- 日次分類（daily）と答え合わせ（review）は、**毎晩自動で更新**されます（前日夜に翌日分の分類を生成し、結果が出た過去日については予測と実績の答え合わせを追記）。
- 確率DB（index）は基盤データの更新に合わせて不定期に再構築します。
- 公開リポジトリのコミット履歴が、そのまま更新履歴です。

## 検証の記録

このプロジェクトは「モデルが市場に勝てるか」の検証から始まり、予想モデルで市場に勝つことはできない（公開情報はオッズに織り込み済み）という結果を受けて、確率の提示に徹する形に転換したものです。検証過程のレポートは開発側リポジトリ（非公開作業領域）に保管しています。
